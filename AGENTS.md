# Python Code
    - Coding Conventions & Style Guide 
    - One statement per line
    - Explicit code
    - Create classes. Use object oriented style
    - Do not hardcode sql queries
    - Include description for every function and class
    - Write comments for important code such as logic
    - do not use short names for variables, functions or classes.
    - Create base classes. Follow rules for Object oriented 
    - prefix constants with C_ for example C_PI=3.14. Exceptions are only the logging messages. Those can remain as a hardcoded arguments
    - use PascalCase for class names
    - Create a model class for each db table
    - Do not hardcode strings or numbers in the code use C_<NAME> = Value. In case the strings are specific to a section or a vendor use C_JIRA_<NAME> or C_GITHUB_<NAME>.
